Full analysis code on GitHub

TCGA download and analysis script

This R script is the only part of the project that downloads TCGA data. It retrieves the mutation data and RNA-seq counts from the GDC, saves them locally, summarises the mutations with maftools, and runs the tumour-versus-normal differential expression analysis with DESeq2. The rest of the analysis (the four replication datasets, rank aggregation, survival models and co-expression network) uses the files saved by this script and is described on the Methods page. The full set of scripts is on GitHub.

# ---- Differential expression analysis --------------------------------

colData(rna)$sample_type <- relevel(colData(rna)$sample_type, ref = "Solid Tissue Normal")

levels(colData(rna)$sample_type)
# should now show: "Solid Tissue Normal" "Primary Tumor"

dds_input <- DESeqDataSetFromMatrix(countData = rna_matrix,
                                     colData = colData(rna),
                                     design = ~ sample_type)

dds_input$sample_type <- relevel(dds_input$sample_type, ref = "Solid Tissue Normal")
levels(dds_input$sample_type)
View(dds_input)
keep = rowSums(counts(dds_input)) >= 10
dds_input = dds_input[keep,]
dds = DESeq(dds_input)

# Save

View(dds)

res
summary(res)

res_df = as.data.frame(res)

write.csv(res_df,
          file = "exports/tables/DEA.csv")

Important lines in the script

These lines affect every expression figure on the website. Click a line of code below to jump to it in the script above.

Setting the reference level

relevel(..., ref = "Solid Tissue Normal") sets normal tissue as the reference group, so a positive log₂ fold change means “higher in tumour” in all later results. If the reference were set the other way round, every fold change on the site would have the opposite sign.

The low-count filter

keep = rowSums(counts(dds_input)) >= 10 removes genes with very few reads before the model is run. These genes give unreliable estimates, and including them would make the multiple-testing correction stricter without adding useful information.

Caching with saveRDS

Each download is saved with saveRDS() and loaded from the saved file afterwards. This means the analysis can be repeated without downloading the data from the GDC again, and every figure is based on the same copy of the data.

Thresholds set in the plot call

pCutoff = 0.05 and FCcutoff = 1 set the thresholds used across the site: an adjusted p-value below 0.05 and at least a two-fold change (a log₂ fold change of 1). They appear as the dashed lines in Results Figure 3 and also decide which genes are included in the network behind Figure 6.

Notes on this script

Why the script looks the way it does, and how the later scripts differ from it.

This is a working script rather than cleaned-up final code, and it is shown as it was written. The ?function help calls and View() calls were used to explore the data in RStudio, and the install commands at the top only needed to run once. Some lines are repeated where a step was re-run after a download failed.

The scripts written later in the project are more structured. They run without manual input, save their inputs and software versions with every result, and stop if a figure doesn't match the analysis.
