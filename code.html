Download and analysis notebook

This is the only file in the project that downloads TCGA data. It gets masked somatic mutation calls and RNA-seq STAR counts from the GDC, saves them so they only need downloading once, summarises the mutations with maftools, and runs the tumour-vs-normal differential expression with DESeq2. The rest of the analysis (the four replication cohorts, rank aggregation, survival models and co-expression network) uses the files this notebook saved, and is described on the Methods page.

R TCGA_BRCA_analysis.R read only

# ---- Differential expression analysis --------------------------------

colData(rna)$sample_type <- relevel(colData(rna)$sample_type, ref = "Solid Tissue Normal")

levels(colData(rna)$sample_type)
# should now show: "Solid Tissue Normal" "Primary Tumor"

dds_input <- DESeqDataSetFromMatrix(countData = rna_matrix,
                                     colData = colData(rna),
                                     design = ~ sample_type)

dds_input$sample_type <- relevel(dds_input$sample_type, ref = "Solid Tissue Normal")
levels(dds_input$sample_type)
View(dds_input)
keep = rowSums(counts(dds_input)) >= 10
dds_input = dds_input[keep,]
dds = DESeq(dds_input)

# Save
saveRDS(dds, file = "exports/r_objects/dds.rds")

# Read it back later
dds = readRDS(file = "exports/r_objects/dds.rds")

View(dds)
res = results(dds)
res
summary(res)

res_df = as.data.frame(res)
View(res_df)

write.csv(res_df,
          file = "exports/tables/DEA.csv")

gene_metadata = as.data.frame(rowData(rna))

Key lines

These lines affect every expression figure on the site. Click a line of code below to jump to it in the source above.

Setting the reference level

relevel(..., ref = "Solid Tissue Normal") sets which group is the reference. With normal tissue as the reference, a positive log₂ fold change means “higher in tumour” in everything that follows. If this were the wrong way round, every figure on the site would point the wrong way and still look believable.

The low-count filter

keep = rowSums(counts(dds_input)) >= 10 removes genes with almost no reads before the model is fitted. They don't carry any information, and keeping them would reduce statistical power, because the multiple-testing correction is spread over every gene tested.

Caching with saveRDS

Each download is saved to disk with saveRDS() and loaded from there afterwards. This means the analysis can be re-run without downloading from the GDC again, and every figure comes from the same stored copy of the data.

Thresholds set in the plot call

pCutoff = 0.05 and FCcutoff = 1 are the same cutoffs used across the site. They're the dashed lines on Results Figure 3 and also the filter that decides which genes go into the network behind Figure 6.

About this notebook

This is a working notebook rather than cleaned-up production code, and I've left it that way on purpose. The ?function help calls and View() calls are from exploring the data in RStudio, and the install block at the top only ran once. Some lines are repeated where I re-ran something after a download failed.

The scripts I wrote after this are stricter. They don't take interactive input, they save their inputs and software versions next to every result, and they stop if a figure doesn't match the analysis. This page shows where the project started.
