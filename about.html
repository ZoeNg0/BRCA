About this project

An independent computational biology project by Zoe Ng, done outside of school coursework between grade 11 and grade 12.

About me

✎

I first got interested in computational biology when I learned that researchers can use genetic data to study diseases like cancer. I was especially curious about how differences in gene expression could affect cancer progression and patient survival. I wanted to see how this works with real data, not just read about other people's research. That led me to PPP4C in breast cancer, and to whether its expression is linked to patient outcomes.

I started by downloading the TCGA breast cancer dataset and its clinical records, plus four more datasets from public databases. The datasets were collected with different methods, so I had to pick the right way to analyse gene expression for each one. Then I combined the results from all five, looked at how gene expression relates to patient survival, built a gene co-expression network, and analysed different groups of genes. I also built this website from scratch in HTML, CSS and JavaScript, including the layout, graphs and code viewer, without any frameworks or charting libraries.

Timeline

  1. August 2026 — scoping and data download

    Choosing the question and the target gene, learning enough R to work with a count matrix, and downloading TCGA-BRCA. Reviewing about thirty public cohorts and picking the four with the most platform and ancestry diversity.

  2. September 2026 — replication and modelling

    Differential expression for each cohort, rank aggregation across all five, the subtype comparison and the survival models. Then the co-expression network and its enrichment testing.

  3. October 2026 — write-up

    Exporting the figures, comparing the published work on PPP4C with my own results, and building this site.

Tools and skills used

R Bioconductor RNA-seq analysis Differential expression Meta-analysis by rank aggregation Survival analysis Network analysis Gene set enrichment Data visualisation Git HTML / CSS / JavaScript Scientific writing

The hardest things to learn weren't the statistics. The first was working out which method each dataset allows. For example, a cohort with no raw counts rules out the model most people would use first. The second was learning to present a result honestly when it's weaker than I'd hoped.

Acknowledgements

This project uses data generated by the TCGA Research Network and by the researchers who deposited the four replication cohorts in the Gene Expression Omnibus. These datasets were shared publicly by people who didn't have to share them, and by patients who agreed to have their tumours studied after their own treatment ended. I couldn't have done this project without them.

Thank you to my mentor and subject matter expert, Mehrdad Moosavi, for his guidance throughout this project.
